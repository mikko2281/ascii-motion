# ASCII Motion

Готовое локальное веб-приложение для преобразования MP4-видео, анимированных GIF и изображений в ASCII- и Unicode/Braille-графику. Видео экспортируется в H.264 MP4 или зацикленный GIF, изображения — одновременно в PNG и UTF-8 TXT. Исходник можно загрузить с компьютера или по прямому URL.

Интерфейс и документация написаны на русском языке. Все пользовательские файлы обрабатываются локально и сохраняются только во временной папке запущенного экземпляра.

## Быстрый запуск

Самый простой вариант — Docker Desktop с Compose:

```bash
docker compose up --build
```

После сборки откройте [http://localhost:5173](http://localhost:5173). Для остановки выполните `docker compose down`; команда `docker compose down -v` дополнительно удалит временный том с заданиями.

## Как пользоваться

1. Откройте вкладку «Видео / GIF», «Изображения» или «Letter Art».
2. Перетащите файл в область загрузки либо вставьте прямую HTTP/HTTPS-ссылку.
3. Выберите стиль, цветовой режим, детализацию и другие параметры. Для фото результат обновляется автоматически, для видео доступен быстрый предпросмотр выбранного кадра.
4. Скачайте MP4/GIF, PNG/TXT или скопируйте текст прямо из интерфейса.

## Возможности

- Drag & Drop и выбор MP4/GIF, проверка расширения, MIME-типа, сигнатуры и последовательности кадров.
- Импорт по прямой HTTP/HTTPS-ссылке: MP4/GIF во вкладке видео и PNG/JPG/WebP во вкладке изображений.
- Сохранение исходных таймингов GIF, включая анимации с переменной длительностью кадров.
- Выбор выходного формата: совместимый MP4 или GIF с рассчитанной палитрой.
- Отдельная вкладка изображений для PNG, JPG и WebP с результатами `.png` и `.txt`.
- Просмотр, копирование и скачивание ASCII-текста прямо в браузере.
- Быстрый живой предпросмотр любого выбранного кадра.
- Адаптивные карточки исходника и результата: горизонтальные, квадратные и вертикальные медиа показываются в своих реальных пропорциях, включая EXIF-поворот фото и поворот мобильного видео.
- Изображения автоматически пересчитываются после изменения стиля, сетки, контраста, яркости, цветов или других параметров; быстрые изменения объединяются в один последовательный запрос.
- Для изображений можно включить точное количество ASCII-ячеек от 100 до 100 000: например, значение 1000 создаёт результат ровно из 1000 символов, включая пробелы.
- Явный переключатель «Чёрно-белое / Цветное»; в цветном режиме каждый символ получает цвет своей области исходного кадра.
- Пять рабочих пресетов для видео и изображений: классический, цветной ASCII, компактный микро-арт, детализированное полотно и Unicode/Braille.
- Отдельный генератор Letter Art для слов и фраз со стилями Standard, Slant, Big, Shadow и 3D; копирование и экспорт в TXT/PNG.
- Ширина сетки, размер символов, яркость, контраст, инверсия, цвета, четыре палитры символов, FPS и качество.
- Автонормализация контраста и регулируемое сглаживание мерцания.
- Сохранение звука с синхронизацией или экспорт без звука.
- Реальный прогресс по этапам, отмена, скачивание результата.
- Последовательная обработка кадров без загрузки всего ролика в память.
- Отдельная уникальная временная папка на каждую задачу; исходник и промежуточное видео удаляются после завершения или ошибки.

## Технологии

- **Frontend:** React, TypeScript, Vite, адаптивный CSS-интерфейс.
- **Backend:** FastAPI, Pydantic, OpenCV, Pillow и NumPy.
- **Медиа:** FFmpeg/FFprobe для чтения, синхронизации звука и экспорта MP4/GIF.
- **Развёртывание:** два Docker-образа, Nginx-прокси и Docker Compose.
- **Контроль качества:** Pytest для API и медиаконвейера, TypeScript production build и GitHub Actions CI.

## Структура

```text
frontend/              React + TypeScript + Vite
  src/App.tsx          рабочий интерфейс и API-клиент
  src/ImageWorkspace.tsx  вкладка изображений, PNG/TXT и копирование текста
  src/styles.css       адаптивная тёмная тема
  nginx.conf           раздача production-сборки и прокси /api
backend/               FastAPI + OpenCV + Pillow + FFmpeg
  app/main.py          API, задачи, валидация, прогресс и очистка
  app/remote.py        безопасное скачивание файлов по прямым URL
  app/video.py         FFprobe, ASCII-рендер и H.264-сборка
  app/image.py         проверка и преобразование PNG/JPG/WebP
  tests/               сквозные тесты видео, GIF, PNG и текста
docker-compose.yml     запуск всего приложения
.env.example           изменяемые ограничения и пути
```

## Требования

- Python 3.11+
- Node.js 20+
- FFmpeg и FFprobe с кодером H.264 (`libx264`, OpenH264 или Media Foundation)
- Моноширинный TTF-шрифт: Consolas/Courier New на Windows или DejaVu Sans Mono в Linux

При старте API проверяет наличие FFmpeg и FFprobe. Если они недоступны, `/api/health` и интерфейс API возвращают понятное сообщение; пользовательские файлы не принимаются до исправления конфигурации.

### Установка FFmpeg

Windows (один из вариантов):

```powershell
winget install --id Gyan.FFmpeg -e
# Закройте и снова откройте терминал, затем:
ffmpeg -version
ffprobe -version
```

macOS:

```bash
brew install ffmpeg
```

Ubuntu/Debian:

```bash
sudo apt update
sudo apt install ffmpeg fonts-dejavu-core
```

Если бинарники не находятся в `PATH`, скопируйте `.env.example` в `.env` и задайте абсолютные пути:

```dotenv
FFMPEG_BINARY=C:/tools/ffmpeg/bin/ffmpeg.exe
FFPROBE_BINARY=C:/tools/ffmpeg/bin/ffprobe.exe
ASCII_FONT_PATH=C:/Windows/Fonts/consola.ttf
```

## Локальный запуск

Backend, из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r backend/requirements.txt
$env:PYTHONPATH = "backend"
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

На Linux/macOS активация окружения выглядит так:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
PYTHONPATH=backend uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

Frontend, во втором терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). Документация API доступна на [http://localhost:8000/docs](http://localhost:8000/docs).

## Настройки

| Настройка | Что меняет |
| --- | --- |
| Ширина сетки | Количество символов по горизонтали; больше — детальнее и медленнее |
| Точное количество символов | Для изображений заменяет ширину сетки и автоматически подбирает число строк с сохранением пропорций |
| Размер символа | Фактический размер глифа в итоговом кадре |
| Контраст / яркость | Тональное разделение и общая светлота |
| Инверсия | Меняет соответствие светлых и тёмных областей |
| Набор символов | Плотность и характер ASCII-штриховки или точечный Unicode/Braille 2×4 |
| Формат результата | H.264 MP4 с возможностью сохранить звук или зацикленный GIF без звука |
| FPS | Частота кадров экспортированной анимации |
| Качество MP4 | CRF/preset для libx264 либо эквивалентный битрейт OpenH264/Media Foundation |
| Цветное | Каждый символ получает цвет соответствующей области исходного кадра |
| Автоконтраст | Растягивает диапазон яркости каждого кадра до 0–255 |
| Сглаживание | Смешивает карту яркости с предыдущим кадром и уменьшает мерцание |

### Стили ASCII

- **Классика** — чёрно-белый результат, где свет и тень передаются разной плотностью символов.
- **Цветной ASCII** — каждый знак окрашивается усреднённым цветом соответствующей области исходного кадра.
- **Микро-арт** — сетка меньшего размера и короткая палитра для компактного, хорошо читаемого силуэта.
- **Полотно** — высокая плотность сетки, детальная палитра, цвет и повышенное качество экспорта.
- **Unicode / Braille** — каждая ячейка кодирует 2×4 точки настоящим символом диапазона `⠀`–`⣿`; работает для фото, видео, монохромного и цветного результата.
- **Текстовый баннер** — отдельная вкладка для Letter Art из введённой фразы со стилями Standard, Slant, Big, Shadow и 3D.

Пресет сразу устанавливает подходящие параметры, после чего каждый из них можно изменить вручную.

Во вкладке изображений отдельный запуск не требуется: после загрузки первый результат создаётся автоматически, а дальнейшие изменения настроек обновляют PNG и TXT с небольшой задержкой. Кнопка «Обновить сейчас» позволяет не ждать эту задержку.

Геометрия сетки учитывает реальную ширину и высоту глифа выбранного моноширинного шрифта, поэтому пропорции исходного изображения сохраняются.

TXT из режима Unicode/Braille сохраняется в UTF-8 и содержит сами Braille-символы. Для корректного просмотра текста нужен шрифт с поддержкой Unicode Braille (в приложении на Windows используется Segoe UI Symbol, в Docker/Linux — DejaVu Sans).

## Конфигурация и ограничения

Переменные из `.env.example` можно передать процессу или через Docker Compose. Для видео действуют значения по умолчанию 200 МБ и 300 секунд; для изображений — 20 МБ и не более 40 мегапикселей. Эти же лимиты применяются к URL-импорту. Видео принимает MP4/GIF, вкладка изображений — PNG/JPG/WebP. GIF не поддерживает аудиодорожку, поэтому при таком выборе результат всегда сохраняется без звука. Первая версия хранит состояние задач в памяти одного процесса и предназначена для одного локального экземпляра.

URL должен вести непосредственно на медиафайл. Адрес страницы видеохостинга, например страницы YouTube, не является прямой ссылкой и будет отклонён. При скачивании проверяется реальная сигнатура файла, запрещены локальные, приватные и служебные сетевые адреса, а каждый адрес перенаправления валидируется повторно.

Максимальный объём загрузки в `frontend/nginx.conf` равен 210 МБ. Если увеличиваете `MAX_UPLOAD_MB` выше 200, увеличьте также `client_max_body_size`.

Сложность примерно линейна по числу выходных кадров и символов. Цветной режим и высокая ширина сетки требуют заметно больше CPU. Для первого запуска рекомендуются 80–120 столбцов, 12–24 FPS и Balanced.

## API

Создать задачу:

```bash
curl -F "file=@input.mp4;type=video/mp4" http://localhost:8000/api/jobs
```

Для GIF используется тот же endpoint:

```bash
curl -F "file=@animation.gif;type=image/gif" http://localhost:8000/api/jobs
```

Создать видеозадачу из прямой ссылки:

```bash
curl -X POST http://localhost:8000/api/jobs/url \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/animation.gif"}'
```

Получить состояние:

```bash
curl http://localhost:8000/api/jobs/JOB_ID
```

Создать предпросмотр на 1,5 секунде:

```bash
curl -X POST http://localhost:8000/api/jobs/JOB_ID/preview \
  -H "Content-Type: application/json" \
  -d '{"grid_width":96,"character_size":10,"timestamp":1.5}'
```

Запустить экспорт:

```bash
curl -X POST http://localhost:8000/api/jobs/JOB_ID/process \
  -H "Content-Type: application/json" \
  -d '{"grid_width":96,"character_size":10,"fps":20,"quality":"balanced","output_format":"mp4","keep_audio":true,"mode":"monochrome"}'
```

Для непосредственного экспорта в GIF передайте `"output_format":"gif"`; параметр `keep_audio` в этом режиме игнорируется.

Отменить, скачать или удалить задачу:

```bash
curl -X POST http://localhost:8000/api/jobs/JOB_ID/cancel
curl -o ascii-video.mp4 http://localhost:8000/api/jobs/JOB_ID/result
curl -X DELETE http://localhost:8000/api/jobs/JOB_ID
```

Полная интерактивная схема запросов доступна в Swagger UI по адресу `/docs`.

### API изображений

```bash
# Загрузка
curl -F "file=@photo.jpg;type=image/jpeg" http://localhost:8000/api/images

# Импорт по прямой ссылке
curl -X POST http://localhost:8000/api/images/url \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/photo.jpg"}'

# Создание PNG и TXT
curl -X POST http://localhost:8000/api/images/IMAGE_JOB_ID/process \
  -H "Content-Type: application/json" \
  -d '{"target_character_count":1000,"character_size":10,"contrast":1.2,"mode":"monochrome"}'

# Скачивание результатов
curl -o ascii-image.png "http://localhost:8000/api/images/IMAGE_JOB_ID/result?format=png&download=true"
curl -o ascii-image.txt "http://localhost:8000/api/images/IMAGE_JOB_ID/result?format=txt&download=true"
```

## Проверка

Тесты генерируют MP4 со звуком, GIF с переменными задержками и тестовый PNG. Проверяются видеоэкспорт, зацикленный GIF, PNG-результат, точная ширина ASCII-текста, MIME-типы и отклонение поддельных изображений:

```bash
cd backend
pytest -q
```

Для запуска теста `ffmpeg` и `ffprobe` должны быть в `PATH`.
